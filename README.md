## 1. 新手指南

### 1.1 这是个什么网站？

「只因梗懂你」是一个梗图社区。你可以：

- 随便逛逛别人整理好的梗
- 搜索某个梗到底什么意思
- 收藏喜欢的梗，以后随时翻
- 自己也会写：把知道的梗整理成条目，帮更多人秒懂

打开首页后，大致会看到：

- **今日热梗**：最近比较火的梗，左右滑着看
- **热门标签**：按主题找内容
- **动态列表**：可切换「推荐 / 最新 / 热议 / 关注」（「关注」需要先登录）
- **快捷入口**：一键去发布、搜索等常用功能

### 1.2 怎么注册和登录？

| 你想做什么 | 怎么操作 |
| ---------- | -------- |
| 注册新账号 | 顶栏点「注册」 |
| 登录 | 顶栏点「登录」 |
| 忘记密码 | 登录页点「忘记密码？」 |

补充说明：

- 目前主要用 **邮箱** 注册、登录和找回密码
- 注册时按页面提示，用邮箱验证码完成校验
- 登录成功后，顶栏会出现你的头像和消息铃铛
- 在别人电脑或公共电脑用完后，建议退出登录

### 1.3 三分钟上手（逛 → 搜 → 收藏 → 发）

1. **逛**  
   打开首页，在动态里切换「推荐 / 最新 / 热议」。登录后还可以看「关注」——只看你关注的人发的梗。
2. **搜**  
   在顶栏搜索框输入关键词，或点热门标签，进入搜索结果。
3. **收藏**  
   打开一条梗的详情，点收藏，选一个收藏夹（没有合适的可以新建；还能设成公开或仅自己可见）。
4. **发**  
   登录后点「发布」，填好名称、介绍、封面和标签再提交。审核通过后，才会出现在首页和搜索里。

## 2. 发布与管理梗

### 2.1 怎么发一条梗？

入口：顶栏「发布」（需要先登录）。

建议按这个顺序填：

1. **梗名称**（必填，最多 50 字）
2. **梗介绍**（必填，最多 500 字）：尽量写清出处、怎么用、什么场合能接
3. **封面图**（必填）
4. **标签**（必填，至少选 1 个）
5. **相关链接**（可选）
6. **相关资源**（可选：补充图或 GIF）
7. 点 **发布梗**

提交后，页面会告诉你当前状态（一般是「审核中」）。只有审核通过，大家才能在首页和搜索里刷到它。

### 2.2 封面、标签、链接怎么填更合适？

#### 封面图

- 格式：JPG / PNG / WebP / GIF
- 大小：不超过 10MB
- 用途：列表卡片和详情顶部都会用它，尽量清晰、主体一眼能看懂

#### 标签

- 从站内标签列表里选（可搜索筛选）
- 至少选 1 个
- 标签能帮助别人在搜索和热门标签里发现你的梗

#### 相关链接（最多 10 条）

每条可以填：

| 字段 | 说明 |
| ---- | ---- |
| 类型 | 通用链接 / 文章 / 视频 |
| 标题 | 比如「原视频出处」（最多 128 字） |
| 网址 | 以 `https://` 开头的外链（最多 500 字） |

适合放：B 站视频、百科、原文报道等延伸阅读。

#### 相关资源（最多 6 张）

- 用来放补充图片或 GIF，和上面的外链是分开的
- 格式和封面一样：JPG / PNG / WebP / GIF

### 2.3 「审核中」「已下架」「彻底删除」分别是什么意思？

在个人主页的「我的发布」里，常见状态如下：

| 状态 | 别人能不能刷到 | 你自己能做什么 |
| ---- | -------------- | -------------- |
| **审核中** | 首页、搜索里看不到 | 本人登录后可以预览详情 |
| **已通过（公开展示）** | 可以 | 可以下架，也可以正常互动 |
| **已下架** | 刷不到 | 30 天内可以申请恢复；也可以彻底删除 |
| **彻底删除** | 不可见 | 不可恢复，发布列表里也不再出现 |

再补充三点：

- 下架之后：别人在首页、搜索里都刷不到这条梗
- **恢复上架**：会重新送审，通过后才会再次出现在首页和搜索
- 请在下架后 **30 天内** 完成恢复，超时可能就恢复不了了

### 2.4 怎么管理自己发过的梗？

主要在个人主页的「我的发布」里操作：

1. 打开个人主页 → **我的发布**
2. 用状态筛选：全部 / 审核中 / 已下架 等
3. 点梗卡片右上角的 **⋮**：
   - **下架梗**：从公开展示里撤下
   - **恢复上架**：重新送审
   - **彻底删除**：删了就回不来，请谨慎

如果某条还在审核中，只有你本人登录后才能预览；别人或未登录访问时，可能会提示链接有误或尚未公开展示。

## 3. 互动与社交

### 3.1 点赞和收藏夹

#### 点赞

- 在梗详情页可以点赞或取消点赞
- 点赞数会显示在卡片和详情里

#### 收藏夹

- 收藏时可以选择放进哪个收藏夹
- 支持新建、重命名、排序，以及把梗在不同夹之间移动
- 收藏夹可以设成：
  - **公开**：别人看你的主页时能浏览这个夹
  - **私密**：只有你自己看得见
- 系统有一个 **默认收藏夹**，不能删除
- 在个人主页的「收藏」分区，可以管理夹里的梗

### 3.2 评论和回复

在梗详情页下方的评论区，你可以：

- 发一条新评论（有的页面还支持配图）
- 回复别人的评论
- 给评论点赞
- 删除自己发过的评论（以页面实际权限为准）

从 **消息中心** 点开「有人评论/回复你」这类消息时，一般会跳到对应梗，并尽量定位、高亮那条评论，方便你直接接着聊。

### 3.3 关注与「关注」动态

- 在用户主页，或梗详情里的作者信息处，可以 **关注 / 取消关注**
- 首页动态切到 **关注**：只看你关注的人已经公开展示的梗
- 「关注」是空的，常见原因：
  - 你还没关注任何人
  - 关注的人暂时没有审核通过、可以公开展示的内容
- 建议先去「推荐 / 热议」里发现喜欢的创作者，再回来看关注流

### 3.4 消息中心：谁会通知我？

入口：

- 顶栏铃铛（鼠标悬停可快速预览）
- 点开后进入完整的消息中心页面

消息大致分两类：

| 类型 | 说明 |
| ---- | ---- |
| 互动 | 点赞、收藏、评论、回复、评论点赞、关注等 |
| 系统 | 审核结果、公告、系统通知等 |

使用小提示：

- 可以用 Tab 切换：全部 / 未读 / 互动 / 系统
- 管理菜单里有：全部已读、清空已读、清空全部
- 点击一条消息：会标记已读，并跳到梗详情、用户主页，或定位到具体评论

如果「明明有人回复了，收件箱却没有」，可以先去原梗评论区确认对方是否真的回复成功；同时确认自己登录的是同一个账号，且没有把消息清空。

## 4. 账号设置

入口：点右上角头像 → **账号设置**

### 4.1 改头像、昵称、签名

在「个人资料」里可以改：

| 字段 | 说明 |
| ---- | ---- |
| 头像 | 支持 jpg / png / webp，建议用正方形；点头像还能放大查看 |
| 昵称 | 最多 50 字 |
| 个性签名 | 最多 255 字 |
| 性别 | 保密 / 男 / 女 |
| 生日 | 可选 |

这些信息会出现在你的个人主页上，也可能出现在你发布的梗相关展示里。改完记得点 **保存资料**。

### 4.2 修改密码

在「账号安全」里：

1. 确认邮箱已绑定，并且已经设置过密码
2. 点 **修改密码**，按提示填写旧密码和新密码
3. 修改成功后，所有设备上的登录都会失效，需要用新密码重新登录

如果页面提示「未设置密码」，请走登录页的 **忘记密码** 流程，把密码初始化好。

### 4.3 安全小建议

- 公共电脑不要勾选长期保持登录；用完请退出
- 定期换密码；改完密码后留意是否需要重新登录
- 邮箱验证码不要告诉别人
- 在账号安全页可以查看安全评级，并刷新安全状态
- 发现异常登录时，立刻改密码，并检查是否还有其他设备在线

## 5. 社区规范

### 5.1 欢迎什么、禁止什么

**欢迎你发布：**

- 有出处、有讲解的梗图和流行语条目
- 清晰的封面、准确的标签、有用的延伸链接
- 友善的评论和讨论

**请不要发布或在评论里出现这些内容：**

- 色情、暴力、血腥、恐怖惊吓等不适合公开展示的内容
- 人身攻击、仇恨言论、骚扰谩骂
- 明显侵权搬运、未授权的商用素材滥用
- 广告刷屏、诈骗引流、恶意外链
- 绕过审核、批量灌水等破坏社区秩序的行为

### 5.2 审核与处理说明

- 新发布的内容默认先进入 **审核**；通过后才会进入首页和搜索
- 违规或质量明显不达标时，可能会被驳回、下架、限制发布，或进一步处理
- 已经下架的内容，作者可以在规则允许的期限内申请恢复（恢复后仍要再审一次）
- 多次或严重违规时，平台有权限制账号功能

### 5.3 知识产权与转载

- 发布前请确认：你有权使用封面图、补充资源和外链指向的内容
- 转载别人作品时，建议在介绍里注明出处，并尽量附上原文或原视频链接
- 如果认为站内内容侵犯了你的权利，可通过站内 **提交反馈** 联系处理

## 6. 常见问题

### 为什么我发了，别人却看不见？

最常见的原因：还在 **审核中**。

- 审核通过前：首页、搜索等公开区域刷不到
- 你本人登录后，可以在「我的发布」或详情预览里看到
- 通过后才会公开展示；如果是「恢复上架」，也会重新进入审核

### 为什么收不到回复消息？

可以按下面逐项排查：

1. 是不是登录了同一个账号
2. 消息中心是不是停在「未读 / 互动」，有没有被清空
3. 到原梗评论区确认对方是否真的回复成功了
4. 从消息点进去一般能定位到对应评论；如果消息没有生成，仍以评论区为准

### 收藏夹别人能看吗？

看你给这个夹设的可见性：

- **公开**：别人访问你的主页时可以浏览
- **私密**：只有你自己看得见  

创建或编辑收藏夹时，可以选择公开还是私密。默认收藏夹以页面显示为准。

### 忘记密码怎么办？

1. 打开登录页
2. 点 **忘记密码？**
3. 按邮箱验证码流程重置密码
4. 成功后用新密码登录  

如果账号安全页提示「未设置密码」，同样走上面的流程即可。

### 「关注」为什么是空的？

常见有两种情况：

- 你还没关注任何人；或
- 关注的人暂时没有 **已通过审核**、可以公开展示的梗  

可以先去「推荐 / 热议」逛逛，关注喜欢的创作者后再回来。

### 下架和彻底删除有什么区别？

| | 下架 | 彻底删除 |
| --- | --- | --- |
| 别人能不能看到 | 不能 | 不能 |
| 自己还能不能找回 | 30 天内可恢复上架（要再审） | 不能 |
| 发布列表里还在吗 | 还在「已下架」里 | 不再出现 |

### 评论区打不开，或提示不能评论？

- 这条梗可能还在审核中、已经下架，或者对游客不可见
- 请确认链接是否正确；如果是你自己发的，可以登录后在「我的发布」里打开预览
